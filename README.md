# Gift-taken

Backend para la web de "regalos deseados" hecha en [Notion](https://baby-samantha.notion.site/Baby-Shower-Samantha-1bc40bcc45ec4589a542924a2b673371).
- El backend está apagado.
- Se alogó en render.com y la BD también.

La idea es tener un __listado de regalos__ para los invitados a una fiesta y que estos puedan elegir que regalo llevarán marcando en la pagina que lo tomarón para evitar que otra persona lleve el mismo regalo.

La pagina básicamente muestra la lista de regalos y si estos están __disponibles__ o no.
Si está disponible el usuario puede tomarlo haciendo que ningún otro usuario lo tome.
